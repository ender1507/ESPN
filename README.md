# EASN

A free companion app for EA Sports College Football 27 dynasties: press conferences, columns, Campusgram, recruiting, Gamecast and more, built from your own dynasty save.

## Download

Get the latest version here: **[EASN-Setup.exe](https://github.com/ender1507/EASN/releases/latest)**

Run it to install, or to update over your current version. Your dynasties and settings are kept.

Windows 10/11 only.
